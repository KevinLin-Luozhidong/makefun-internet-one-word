# make.fun — The Internet in One Word

Bounty: https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b
Prize: $10 shared by the top 3 entries ($5 / $3 / $2).

## Entry

`main.py` — Python, standard library only. It writes one word describing
the whole internet to `/output/entry.txt`. A judge model compares entries
two at a time, weighing how funny the word is, how well it fits the
internet as a whole, and how surprising it is.

The word is **Labyrinth**: the internet is a maze you wander for hours —
every corridor promises an exit, every turn opens three more corridors,
and you emerge somewhere you never meant to go, carrying something you
never meant to find.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.txt
python3 main.py                          # writes /output/entry.txt
```
